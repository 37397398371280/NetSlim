NetSlim.js Documentation

NetSlim.js is a zero-dependency JavaScript library that reduces outgoing payload sizes, eliminates duplicate network requests, caches repeat GET calls, optimizes image uploads, and provides built-in gzip / deflate compression and response unpacking helpers.

Two Operating Modes:
  • mode: 'compatible' (Default) — Works with zero server changes by minifying JSON, stripping optional empty values, resizing oversized image uploads, coalescing concurrent requests, and caching repeat GET reads.
  • mode: 'compressed' — Compresses large outgoing text/JSON bodies using native CompressionStream (gzip or deflate) and attaches Content-Encoding for endpoints or edge workers configured to unpack compressed request bodies.

2. Installation

Via Script Tag (Browser)

<script src="./netslim.js"></script>
<script>
  const slim = new NetSlim({ cacheTtlMs: 10000, debug: true });
  slim.enableGlobal();
</script>

Via CommonJS / Bundler

const NetSlim = require('./netslim.js');

const slim = new NetSlim({
  mode: 'compatible',
  cacheTtlMs: 15000,
  persistCache: true
});
slim.enableGlobal();

3. Quick Start

Once slim.enableGlobal() is called, existing fetch() calls across your app automatically benefit from request deduplication, caching, JSON minification, image optimization, and envelope unpacking. 

const slim = new NetSlim({
  mode: 'compatible',
  cacheTtlMs: 10000,
  persistCache: true,
  stripNulls: false,
  maxImageWidth: 1920,
  imageQuality: 0.85,
  debug: true
});

slim.enableGlobal();

// 1. Concurrent identical GET calls are merged into 1 network request
const [userA, userB] = await Promise.all([
  fetch('/api/profile').then(r => r.json()),
  fetch('/api/profile').then(r => r.json())
]);

// 2. Pretty-printed JSON bodies are minified automatically before sending
await fetch('/api/settings', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ theme: 'dark', notifications: true }, null, 4)
});

// 3. Check savings anytime
console.log(slim.getStats());

4. Configuration Options

Option Type Default Description
mode 'compatible' | 'compressed' 'compatible' 'compatible' keeps requests valid for untouched servers. 'compressed' sends Content-Encoding compressed bytes for large string bodies.
format 'gzip' | 'deflate' 'gzip' Compression format used by compress(), decompress(), and mode: 'compressed'.
autoUnpackResponse boolean true Automatically unpacks JSON responses shaped like { _ns: "gzip" | "deflate" | "br", data: "<base64>" }.
brotliDecompress function | null null Optional async decoder (bytes: Uint8Array) => Uint8Array | string used when unpacking 'br' payloads.
cacheTtlMs number 10000 Time-to-live (in ms) for cached GET responses. Set to 0 to disable caching.
persistCache boolean false Persists cached GET text/JSON responses in localStorage across page reloads.
storagePrefix string 'netslim:' Key prefix used when persistCache is enabled.
stripNulls boolean false Removes null and undefined properties from JSON request bodies when enabled.
stripEmptyStrings boolean false Removes empty string ("") properties from JSON request bodies when enabled.
maxImageWidth number 1920 Scales down uploaded image blobs/files wider than this pixel width while preserving aspect ratio.
imageQuality number 0.85 Canvas export quality (0–1) for re-encoded images. Keeps original if larger.
compressThreshold number 512 Minimum byte length before mode: 'compressed' compresses a string body.
debug boolean false Logs cache hits, coalesced requests, and unpacked payloads to the console.

5. API Methods

Method Signature Behavior
enableGlobal() () => void Overrides window.fetch with slim.fetch.
disableGlobal() () => void Restores the original native window.fetch.
fetch(url, options) (RequestInfo, RequestInit?) => Promise<Response> Runs body optimization, cache lookup, in-flight coalescing, network fetch, and response envelope unpacking.
compress(input, format?) (string | ArrayBufferView, string?) => Promise<Uint8Array> Compresses a string or byte buffer using native CompressionStream.
decompress(input, format?, asText?) (string | Uint8Array | ArrayBuffer, string?, boolean?) => Promise<string | Uint8Array> Decompresses Base64 or binary bytes back into text (default) or Uint8Array.
bytesToBase64(bytes) (Uint8Array) => string Encodes compressed binary bytes into a Base64 string.
base64ToBytes(b64) (string) => Uint8Array Decodes a Base64 string back into a Uint8Array.
minifyJson(str) (string) => string Parses and compacts JSON strings without altering data values (unless strip flags are enabled).
optimizeImage(blob) (Blob) => Promise<Blob> Resizes and re-encodes eligible raster images on an HTML5 canvas, returning the smaller blob.
getStats() () => object Returns { requests, cacheHits, coalesced, unpackedResponses, bytesSaved }.

6. Compression, Unpacking & Brotli Hook

You can call compress() and decompress() directly to shrink data stored in localStorage, IndexedDB, or Web Workers, or to unpack compressed JSON envelopes. 

// Direct compression & unpacking
const raw = JSON.stringify({ records: Array(150).fill({ status: 'ok', role: 'member' }) });
const gzBytes = await slim.compress(raw, 'gzip');
const base64 = slim.bytesToBase64(gzBytes);

// Restore back to exact original JSON string
const restored = await slim.decompress(base64, 'gzip', true);

// Optional Brotli ('br') decoder integration (e.g., using a WASM Brotli decoder)
const slimWithBrotli = new NetSlim({
  brotliDecompress: async (bytes) => {
    return myBrotliWasmModule.decompress(bytes); // returns Uint8Array
  }
});

7. Zero-Server-Setup Reality Check

Why mode: 'compatible' is the default:

Standard HTTP servers automatically compress responses (Server -> Browser) using gzip or Brotli when configured, and browsers decompress them natively. However, an untouched server that expects plain JSON in a POST request body will reject raw compressed bytes unless the server is configured to decompress Content-Encoding request bodies. Keep mode: 'compatible' for third-party or untouched APIs, and use mode: 'compressed' only for endpoints/workers you control that unpack compressed requests.
